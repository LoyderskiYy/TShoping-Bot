# 🛒 Telegram Bot Магазин с оплатой Bitcoin (BTC)

Асинхронный полнофункциональный Telegram-бот интернет-магазин цифровых товаров на **Python 3.10+ / 3.13+**, построенный на фреймворке **aiogram 3.x** и **SQLAlchemy 2.0 (SQLite)**.

---

## 🌟 Возможности

### 👤 Для покупателей:
* **Меню /start**: удобная навигация с постоянными кнопками:
  * 🛍 **Каталог** — просмотр категорий и товаров, карточки с ценой и наличием, мгновенная покупка с баланса.
  * 📦 **Заказы** — история всех оплаченных заказов с датой, ценой и просмотром выданного содержимого (ключи/аккаунты/ссылки).
  * 👤 **Мой профиль** — отображение Telegram ID, имени и текущего баланса в рублях:
    * 💳 **Пополнение баланса через Bitcoin (BTC)**:
      * Ввод желаемой суммы пополнения в рублях.
      * Автоматический расчет суммы в BTC по **актуальному биржевому курсу** (Blockchain.info / CoinGecko / Binance).
      * Выставление счета с указанием кошелька администратора.
      * Автоматическая проверка входящей транзакции в блокчейне через публичные эксплореры (`mempool.space` / `blockstream.info`) при нажатии кнопки **«🔄 Проверить оплату»**.
      * Возможность ручного ввода хэша транзакции (**TxID**) с валидацией и защитой от повторного использования.
  * 💬 **Поддержка** — отправка обращений администрации магазина с фиксацией тикетов в базе данных и доставкой ответов напрямую в чат с ботом.

### 👑 Для администраторов:
* **🌐 Полноценная Web-панель администратора (FastAPI + Tailwind CSS)**:
  * Доступна в браузере по адресу `http://localhost:8000` (логин: `admin`, пароль из `.env`).
  * Дашборд со сводными метриками: выручка, заказы, объем BTC-депозитов, тикеты.
  * Управление товарами: удобное инлайн-изменение количества товара на складе прямо в таблице.
  * Модальное окно добавления товара с поддержкой нескольких весов, индивидуальных цен и остатков.
  * Управление городами и районами.
  * Просмотр всех заказов и истории выданного контента.
  * Управление Bitcoin-депозитами с возможностью ручного подтверждения.
  * Система тикетов поддержки с ответом прямо из веб-панели в Telegram пользователя.
* **Управление каталогом и параметрами через Telegram-бота (/admin)**:
  * Создание и удаление категорий.
  * Добавление товаров с уточнениями: выбор **Города и Района**, **Типа** (Магнит, Тайник, Доставка) и **Веса** (например 200г, 500г, 1кг) с **индивидуальной ценой** за каждый вес.
  * **Простое указание остатка числом**: администратор просто отправляет число (например `7`), и на складе устанавливается 7 шт. При каждой покупке число автоматически списывается.
  * Редактирование цены и описания существующего товара.
  * Удаление товаров.
* **Настройка Bitcoin-кошелька**:
  * Просмотр и изменение адреса BTC-кошелька для приема платежей прямо из меню бота или через веб-панель.
* **Тикет-система поддержки**:
  * Просмотр открытых обращений пользователей.
  * Ответ на вопрос в один клик с мгновенной отправкой ответа пользователю в бота.
* **Ручное начисление баланса**:
  * Возможность начислить рубли пользователю по его Telegram ID.
* **Статистика**:
  * Общее число пользователей, товаров, выполненных заказов, общая выручка, сумма депозитов в BTC и количество открытых тикетов.

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей
Убедитесь, что установлен Python 3.10 или новее:
```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации (.env)
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
```ini
# Токен вашего бота (получить у @BotFather)
BOT_TOKEN=ТОКЕН

# Telegram ID администраторов через запятую (узнать свой ID можно у @userinfobot)
ADMIN_IDS=ID

# Путь к файлу базы данных SQLite
DATABASE_PATH=shop.db

# Начальный Bitcoin-кошелек (можно изменить позже в /admin)
DEFAULT_BTC_WALLET=BTC

# Минимальная сумма пополнения в рублях
MIN_DEPOSIT_RUB=100.0
```

### 3. Запуск бота
```bash
python bot.py
```

При первом запуске бот автоматически создаст базу данных SQLite и применит все необходимые таблицы и настройки.

│
├── states/
